# NBC Compiler Tooling Directory

To enable automatic on-the-fly compilation of NXC source code directly into `.rxe` executables:

1. Download `nbc.exe` (Next Byte Codes compiler for LEGO Mindstorms NXT) or copy it from your BricxCC installation.
2. Place `nbc.exe` in this folder: `nxt-scratch/tools/nbc.exe`.

The NXT-Scratch IDE dev server will automatically detect it and compile Blockly programs into `.rxe` binaries with one click of **Flash to NXT**.

> **Note**: Even without `nbc.exe`, you can always use the **Upload .rxe** button in the IDE to upload and execute any precompiled `.rxe` file to your NXT brick over Bluetooth!
